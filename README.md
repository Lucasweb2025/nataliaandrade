# Nathalia Andrade — Salão de Beleza

Repositório do site publicado no **GitHub Pages**.

- **Site:** https://salaonathaliaandrade.com.br/
- **Código-fonte (React):** pasta [`nathalia-react/`](nathalia-react/)

## Deploy

A raiz do repositório contém o **build de produção** (`index.html`, `assets/`, `gallery/`, …).  
Para alterar o site, edite em `nathalia-react/`, rode `npm run build` e copie `nathalia-react/dist/*` para a raiz.

Documentação técnica completa: [nathalia-react/README.md](nathalia-react/README.md)
